## 만드는 원칙 (v12)

- 한 번에 하나씩: 새 요소가 혼자 뜨고, 읽을 시간을 준 뒤에 다음 요소가 와요. 앞의 요소는 걷히거나 옅어져요.
- 질문이 먼저, 답은 그다음: 말풍선 → 생각, 단서 질문 → 실 → 기록, 줄 → 실 → 카드 → 형광펜 순서예요.
- 읽는 시간: 제목과 말풍선 같은 한 문장은 초당 6~8음절로 읽을 만큼 머물러요. 기록 카드와 요약처럼 글이 많은 곳은 다 읽기보다 형광펜이 짚는 곳을 따라가게 했어요.
- 카메라: 확대했다가 줄였다가 다시 확대하지 않아요. 다음 자리로 옆걸음으로 옮겨 가요.

## v10에서 바꾼 것 (2026-11-06 3차 피드백)

- **길이:** 85.4초 → 119.5초. 정보가 한 번에 뜨던 곳을 비트로 나눴어요. 로고는 114초(`D1 + 46마디`)예요.
- **장면 카드:** 별을 빼고, 번호에서 이름으로 빛이 한 번 지나가요. 빠르기는 그대로예요.
- **01:** 제목을 "앱마다 흩어진 기록을, / 한 번에 찾아 요약합니다"로 줄이고 크게. 통화 말풍선을 이해한 뒤 위로 올리면 말풍선이 걷히고 검색창을 크게. 검색 버튼을 손으로 누른 다음에 작아짐. 기록은 하나씩. 요약은 완결된 세 문장을 크게, 상자 오른쪽을 채움. 메일 보내기 버튼 삭제("최종본은 민수 님 메일에 있어요"), 답변 말풍선을 크게 한 줄씩.
- **02:** 단서 질문을 진한 말풍선으로 키우고, 질문이 혼자 뜬 다음에 실과 기록이 와요. 사진에서 답으로 줌아웃 없이 옆으로 넘어가요.
- **03:** 대화를 조금 천천히, 플로팅은 탑승권 → 위치 → 아내 카톡 → 링크 미리보기 순서로 하나씩. 갤러리 사진을 빼고 아내 카톡에 링크와 미리보기를 더했어요(아내는 '갈색병'이라고만 말하고, 이름은 미리보기 제목에 있어요). 위치는 인천공항 면세점 인근. 추천은 한 줄.
- **카톡 미리보기 모양:** URL 말풍선 아래 흰 카드, 카드 안은 2:1 이미지 → 제목 → 도메인. 실제 화면 예시(요즘IT 기사의 카카오톡 캡처)를 보고 맞췄어요. 카카오 스크랩은 페이지의 Open Graph 태그로 미리보기를 만들어요. 병 사진은 전에 생성한 그림을 벽만 좌우로 늘린 것이고(`소스/assets/img/ssg-preview.jpg`), 링크 주소는 지어낸 것이에요.
- **끝 화면:** 5초 → 5.5초.
- **음악:** 36마디 뒤(63.6초)에 21마디로 돌아가 16마디, 다시 36마디 뒤(102초)에 35마디로 돌아가 2마디를 더했어요. 단서 질문이 뜰 때 아주 작은 효과음을 더했어요.

## 고치는 방법

1. 장면을 고쳐요.
   - 타임라인(초 단위)은 `소스/main.js`, 문구는 `소스/index.html`에 있어요.
   - 장면 시각은 `main.js` 위쪽 "장면 시각"에 모여 있어요(`C1`, `P0`, `T2`, `s2`, `dragT`, `s3`, `pTapW` …).
   - `D1`(3.6초, 곡이 터지는 순간)과 `BAR`(2.4초)는 기본 곡에 맞춘 값이에요. 로고(`LOGO`)는 답장을 읽을 시간(`LOGO_MIN`) 뒤의 첫 마디 첫 박으로 자동으로 정해져요.
   - 지금은 `LOGO = D1 + 38마디`(94.8초)예요. 로고 시각이 바뀌면 `tools/music.py`의 편집점(segs)도 같이 고쳐요. 안 맞으면 `music.py`가 멈추고 알려 줘요.
2. 화면을 바꿨으면 끝 장면의 세 화면을 다시 찍어요: `node tools/trio.cjs`
3. 효과음 시점을 뽑아요(손 위치도 함께 출력): `node tools/render.cjs --events`
4. 음악을 다시 만들어요: `~/.cache/weave-tools/venv/bin/python tools/music.py`
   - 곡 파일은 `~/.cache/weave-tools/music/<번호>.mp3`에 있어요. 없으면 위 표의 주소에서 받아요.
5. 확인용 정지 화면을 찍어요(누르는 자리에 빨간 점): `node tools/render.cjs --debug --stills 20,35,45,65,70`
6. 완성본을 찍어요(약 8분): `node tools/render.cjs --fps 60 --jobs 10 --blur --audio out/bgm.wav --out out/weave_intro.mp4`
