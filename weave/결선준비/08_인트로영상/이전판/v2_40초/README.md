# 결선 인트로 영상 (v2, 39.6초)

발표 시작에 트는 제품 광고 느낌의 훅 영상이에요. 1920×1080·60fps, H.264 + AAC라서 PowerPoint의 삽입 → 비디오에 그대로 넣을 수 있어요.

v1(28초)은 `이전판/v1_28초/`에 소스·영상·음악째로 남겨 두었어요.

## v1에서 바꾼 것 (2026-10-29 피드백)

- **음악:** Rewind 광고 음악을 분석해서 다시 만들었어요(약 114 BPM, 다장조, 저음 위주, 고른 그루브). 로즈 피아노 코드(Fmaj9–Em7–Dm9–G13), 둥근 베이스, 부드러운 킥·림·셰이커로 차분하게 갔어요. 톡톡 튀던 플럭 아르페지오와 음계 팝 효과음은 뺐어요.
  - 대역별 에너지가 Rewind와 비슷해요: 120Hz 이하 63% / 120–400Hz 27% (Rewind는 69% / 20%).
  - 효과음은 작고 따뜻하게 바꿨어요(로즈 차임, 부드러운 바람 소리).
- **속도·문구:** 길이를 28초에서 40초 안으로 늘리고 장면마다 2~5초를 머물게 했어요. 배지와 설명 문장은 빼고 헤드라인 한 줄만 남겼어요. 통화 장면 문구에서 통화 관련 말("전화를 끊지 않고")을 뺐어요.
- **와인 장면 하나로:** 두 번 나오던 와인 장면을 휴대폰 → 확대 → Weave 아이콘 → 휴대폰 치움 → 단서 엮기 → 다시 휴대폰 순서로 합쳤어요.
- **카메라:** Material 3 Expressive처럼 휴대폰을 확대·축소하고 화면 가운데·오른쪽·왼쪽으로 옮기며 UI를 크게 보여 줘요.
- **손 위치:** 글꼴을 다 불러오고 카메라·시트가 움직인 뒤의 실제 자리를 재서 눌러요. 다섯 군데 모두 디버그 화면(`?debug=1`)으로 확인했어요.
- **연결 보이기:** 통화 장면에서는 흩어진 세 기록이 실로 들어와 카드가 되고, 카드끼리 점선으로 이어져요. 카톡 장면에서는 GPS 위치와 단체방 기록이 추천 문장으로 이어져요.
- **배경:** 오른쪽 아래 노란빛을 빼고 보라빛 그라데이션만 남겼어요.
- **첫 문구:** "잠깐만, 찾아볼게…" 대신 "카톡이었나, 사진이었나, 캘린더였나…"를 넣었어요. 기록 조각 수는 24개에서 14개로 줄이고 움직임은 느리게 했어요.
- **엔드 카드:** Weave 그라데이션이 W의 진한 보라(#4E36CF)에서 시작해 #8F66FF로 끝나요. 연한 라벤더가 배경에 묻히던 문제를 고쳤어요. 글자 그림자가 잘려 생기던 희미한 사각 경계도 없앴어요.

소리는 직접 들어 보지 못했어요. 스펙트로그램, 대역별 에너지, 음량(약 −15.3 LUFS, 최대 −2.8 dBFS)으로만 확인했어요.

## 고치는 방법

1. `소스/main.js`의 타임라인(초 단위)과 `소스/index.html`의 문구를 고쳐요.
2. 효과음 시점을 뽑아요: `node tools/render.cjs --events` (손 위치도 함께 출력)
3. 음악을 다시 만들어요: `~/.cache/weave-tools/venv/bin/python tools/music.py`
4. 확인용 정지 화면을 찍어요(누르는 자리에 빨간 점이 찍힘): `node tools/render.cjs --debug --stills 10.9,18.4,31.9`
5. 완성본을 찍어요(약 3분 30초): `node tools/render.cjs --fps 60 --jobs 10 --blur --audio out/bgm.wav --out out/weave_intro.mp4`

실행 환경은 `~/.cache/weave-tools`예요. 여기에 node의 playwright-core·gsap, `bin/ffmpeg`, 파이썬 venv(numpy, scipy, Pillow, python-pptx, imageio-ffmpeg, yt-dlp)가 들어 있어요.
