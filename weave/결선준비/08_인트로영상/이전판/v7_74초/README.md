## v6에서 바꾼 것 (2026-10-30 두 번째 피드백)

- **장면 문장:**
  - 장면 뱃지("01 · 단서로 찾기" 등)를 세 장면 모두에서 뺐어요. 장면 카드가 이미 번호와 제목을 보여 줘요.
  - 대신 문장 글자를 키웠어요: 01 54 → 60px, 02 46 → 52px, 03 48 → 54px.
- **01:** 검색어가 바뀐 뒤 보라 밑줄을 검색창 너비가 아니라 "배비치 소비뇽 블랑" 글자 길이에 맞췄어요.
- **02:**
  - "노트였나… 메일이었나…"는 내 생각이라 왼쪽 문장 아래로 옮겼어요. 휴대폰이 확대될 때 그 위에 글자가 겹치던 문제예요.
  - 손잡이 확대는 휴대폰 왼쪽 끝이 통화 말풍선을 넘지 않게 했어요.
  - 검색창 확대는 휴대폰 윗부분이 말풍선 아래로 내려오게 해서, 말풍선과 휴대폰이 겹치지 않아요.
- **03:**
  - 끝부분에서 "엄마, 전에 먹고 싶다던 무화과시루 사갈까?"를 입력할 때는 입력창을 크게(2.35배) 보여 줘요. 보낸 뒤에는 보낸 말과 답장을 크게(2.05배) 보여 줘요.
  - 가족 단체방은 카카오톡처럼 이름 → 사진 → 말풍선 차례로 쌓았어요. 이름과 말풍선 사이가 멀던 문제예요.
- **문구:** 뱃지 세 개를 뺀 것 말고는 바뀐 문구가 없어요.
- **음악:** 효과음 시점이 그대로라 v6 음악을 그대로 썼어요.

## 고치는 방법

1. 장면을 고쳐요.
   - 타임라인(초 단위)은 `소스/main.js`, 문구는 `소스/index.html`에 있어요.
   - 장면 시각은 `main.js` 위쪽 "장면 시각"에 모여 있어요(`C1`, `P0`, `T2`, `s2`, `dragT`, `s3`, `pTapW` …).
   - `D1`(11.7초, 곡이 터지는 순간)과 `BAR`(2.4초)는 기본 곡에 맞춘 값이에요. 로고(`LOGO`)는 답장을 읽을 시간(`LOGO_MIN`) 뒤의 첫 마디 첫 박으로 자동으로 정해져요.
   - 지금은 `LOGO = D1 + 24마디`예요. 로고 시각이 바뀌면 `tools/music.py`의 편집점(segs)도 같이 고쳐요.
2. 도입부를 바꿨으면 프레임 검사를 다시 돌려요: `node tools/check_hook.cjs`
3. 효과음 시점을 뽑아요(손 위치도 함께 출력): `node tools/render.cjs --events`
4. 음악을 다시 만들어요: `~/.cache/weave-tools/venv/bin/python tools/music.py --all`
   - 곡 파일은 `~/.cache/weave-tools/music/<번호>.mp3`에 있어요. 없으면 위 표의 주소에서 받아요.
5. 확인용 정지 화면을 찍어요(누르는 자리에 빨간 점): `node tools/render.cjs --debug --stills 17.05,29.35,32.35,62.25`
6. 완성본을 찍어요(약 6분): `node tools/render.cjs --fps 60 --jobs 10 --blur --audio out/bgm.wav --out out/weave_intro.mp4`
7. 곡2를 입혀요(화면은 다시 찍지 않음): `~/.cache/weave-tools/bin/ffmpeg -i out/weave_intro.mp4 -i out/bgm_35.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -shortest 결과.mp4`
