## v4 → v5에서 바꾼 것 (2026-10-29 두 번째 피드백)

- 도입: 조각 밝기를 매 프레임 계산(자막과 어긋나던 문제 해결), 앱 이름 보라색, "메모였나…" → "노트였나…", 제목과 조각이 겹치지 않게
- 01: 뱃지·문장을 위로, 사슬 단계마다 카메라 확대, 입력하기 뒤 실제 검색 흐름, "찾은 답" → "자동 완성 추천"
- 02: 통화 말풍선(PPT 문구) 먼저, 위로 올리기 효과, 검색창 확대, 실 세 가닥 한 번에, 검색어 "A사 시연 관련 자료" → "어제 A사 시연 준비"
- 03: 휴대폰 왼쪽·플로팅 오른쪽, 대화를 하나씩 확대, 버튼 반짝 → 누름, 답장 간격 0.5초 → 1.65초, 문장 "대화와 지금 위치를 엮어, 보낼 말을 먼저 건네요" → "지금 상황과 지난 기록을 엮어, 필요한 걸 먼저 건네요", 가족 단체방을 PPT의 2주 전 대화로
- 끝: "Weave got it." → "Weave got it!", Galaxy AI 표시를 오른쪽 아래(삼성 갤럭시 XR 광고의 파트너 표시 자리)
