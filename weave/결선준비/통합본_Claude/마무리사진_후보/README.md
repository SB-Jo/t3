# 마무리 세 장(39~41쪽)에 쓸 사진 후보

26장이에요. 모두 Unsplash에서 받았고 Unsplash 라이선스(무료로 쓰고 고치고 배포할 수 있음, 출처 표기 의무 없음)예요.
16:9로 자르고 1920×1080으로 줄였어요. 덱의 39~41쪽은 아직 바꾸지 않았어요.

- `후보_한눈에.jpg`: 26장을 묶음별로 한 장에
- `시안_한눈에.jpg`: 지금 39~41쪽의 글과 어둠을 얹어 PowerPoint로 찍은 모습(네 조합, 40쪽에 놓을 다른 사진 여섯 장)
- 다시 찍기: `python tools/closing_try.py` (조합은 그 파일의 `TRIES`)
- 덱에 넣을 때: `slides_new.py`의 `s_end1(photo=…)`, `s_end2(photo=…, hand=…)`, `s_end3(photo=…)`

39쪽과 41쪽은 글이 화면 한가운데에 놓여서, 가운데가 비어 있는 C 묶음과 A5가 맞아요. 40쪽은 손글씨 '순간'만 있어서 어느 사진이든 놓을 수 있어요.
