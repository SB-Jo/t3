## 장의 흐름

| 때 | 말 | 화면 |
| --- | --- | --- |
| 장이 열림 | 저희 설문에서 83.8%는 어느 앱에 남겼는지 몰라 앱을 하나씩 열어 봤고, | 위 제목 'AS-IS'. 첫 고리 얼굴이 한가운데에 뜨고, 숫자를 말할 때 고리가 83.8%까지 차오름. 불편 문장 '어느 앱인지 몰라 / 하나씩 열어 봤어요' |
| 클릭 1 | 앞서 보신 것처럼 93.8%는 정확한 이름이 떠오르지 않아 검색하지 못했으며, | 첫 얼굴이 왼쪽으로 비키고 둘째(93.8%)가 가운데에. '정확한 이름이 떠오르지 않아 / 검색하지 못했어요' |
| 클릭 2 | 82.4%는 부탁이나 약속을 잊었다가, 나중에야 떠올렸습니다. | 셋째(82.4%)가 오른쪽에. '챙겨야 할 부탁, 약속을 / 나중에야 떠올렸어요' |
| 클릭 3 | Weave가 있다면, 통합 검색, 단서로 찾는 기억, 먼저 건네는 기억을 통해, 찾는 시간은 줄이고, 놓친 기억은 되살립니다. | 아래 가운데에 Weave 아이콘이 뜨고 위 제목이 뒤집혀 'TO-BE'. 기능을 말할 때마다 아이콘에서 실이 뻗어 그 칸에 닿고, 닿은 칸의 숫자가 0까지 줄어드는 동안 고리가 보라로 닫히고 얼굴이 웃음. 숫자 자리에 달라진 두 줄이 올라옴. '찾는 시간은'에서 아래 제목 '찾는 시간은 줄이고, 놓친 기억은 되살립니다' |

달라진 두 줄은 왼쪽부터 '어느 앱인지 몰라도 / 통합 검색으로 찾아요', '정확한 이름을 몰라도 / 단서로 찾아요', '챙겨야 할 부탁, 약속을 / 묻기 전에 알려 줘요'예요.

## 앞선 차수

| 차수 | 후보 | 받은 검토 |
| --- | --- | --- |
| 1차 | A 실 세 가닥, B 세 물음, C 물결 (설문마다 얼굴 열 개) | 사람 열 개가 보기 좋지 않다 → 고리 그래프와 표정을 합치기 |
| 2차 | D 고리 얼굴, E 고리 속 얼굴, F AS-IS → TO-BE 뱃지, G 줄어드는 숫자, H 몸통 있는 사람 | 표정이 변하는 것은 좋은데, 숫자와 그림이 여전히 그 퍼센트를 가리켜 어색하다 → 3차 |
| 3차 | J 숫자가 기능 이름으로, K 숫자가 물러남, L 숫자가 0으로 | L이 좋다. AS-IS와 TO-BE 제목, 뻗어 가는 실, 숫자 가운데 맞춤, 조금 느리게, 글을 더 짧게 → 지금 판 |

앞선 차수의 영상, 후보를 모은 덱, 한눈에 그림은 이 폴더의 `이전판/`에 있어요(작업 컴퓨터에만 두고 저장소에는 올리지 않아요). 장은 `fx_new.py`에 그대로 있어서 `tools/fx_try.py --only L`처럼 다시 찍을 수 있어요.

## 다시 만들기

```
~/.cache/weave-tools/venv/bin/python tools/fx_try.py              # 지금 장의 영상, 덱, 한눈에.jpg
~/.cache/weave-tools/venv/bin/python tools/fx_try.py --quick M    # 지금 장만 낭독 없이 빨리 찍어 봄(out/fx_try)
~/.cache/weave-tools/venv/bin/python tools/fx_try.py --only L     # 앞선 후보를 다시 찍음(이전판/에 나옴)
```

- 지금 장은 `fx_new.py`의 `s_fx`예요(후보 표에서는 M, `CURRENT`). 화면 글은 `FX_ROWS`, 대본은 `FX_NOTE`, 말에 맞춘 때는 `FX_CUES`, 놓인 자리와 빠르기는 `FX_RO`부터 `FX_TURN`까지의 값이에요.
- 입은 웃는 모양으로 그려 두고 처음 뜰 때 반 바퀴 돌려 둬요. 그래서 편집 화면과 내보낸 그림에는 마지막 모습(웃는 얼굴)이 나와요.
- 줄어드는 숫자는 잠깐씩 보이는 숫자 열세 개를 차례로 바꿔 끼워 줄어드는 것처럼 보이게 해요.
- 입꼬리를 돌리는 효과(`spin`)와 뒤집히는 효과(`flip_in`, `flip_out`)는 `../09_HowItWorks/장표5_claude/motion.py`에 있어요.
