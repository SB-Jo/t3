## 같은 점

- 그림 전체를 장 한가운데에 맞췄어요. Weave는 오른쪽 위에 있어요.
- 제목('한 번의 검색을 넘어, 단서를 이어 찾는 검색으로'), 말할 글, 각주는 지금 35쪽 그대로예요.
- 기존 기능 넷은 이름을 말할 때 하나씩 뜨고, 클릭하면 Weave가 떠요(지금 장과 같은 차례).

## 후보

| | 그림 | 둘 중 하나라는 점을 보이는 법 | 기존 기능의 자리 |
| --- | --- | --- | --- |
| 가 두 띠 | 세로는 띠 둘(한 번에 찾는 검색 / 단서를 이어 찾는 검색), 가로는 찾는 범위(쓰는 글, 앱 하나, 여러 앱) | 띠가 둘이라 눈금이 아니에요. 위 띠는 처음엔 점선으로 비어 있다가 클릭하면 켜지며 Weave가 떠요 | 아래 띠 안에 높낮이를 달리해 놓여요. 띠 안의 높낮이에는 뜻이 없어요 |
| 나 넓이와 깊이 | 가로 찾는 범위(좁게 → 넓게), 세로 찾는 깊이(얕게 → 깊게). 눈금과 점선 없이 끝 이름만 | 보이지 않아요. 축 이름을 이어진 것으로 바꿔 그림과 말이 어긋나지 않게 하는 쪽이에요 | 얕은 쪽에 들쭉날쭉. 높낮이는 맥락을 얼마나 읽는지에 따라 조금만 달리했어요 |
| 다 네 칸 | 2×2 칸. 가로는 앱 하나 안에서 / 여러 앱에 걸쳐, 세로는 한 번에 / 단서를 이어 여러 단계로 | 가로와 세로 모두 칸으로 나뉘어요. 클릭하면 오른쪽 위 칸이 켜지며 Weave가 떠요 | 아래 두 칸에 둘씩 |
| 라 계단 | 계단 두 단. 아랫단이 한 번에 찾는 검색, 윗단이 단서를 이어 찾는 검색 | 한 단 위라는 것이 그대로 보여요. 찾는 범위는 그림에 없어요 | 아랫단 위에 나란히 |

나의 높낮이: 쓰는 글만 다듬는 Writing Assist가 가장 아래, 물은 말로 한 번 검색하는 Finder가 그 위, 지금 보는 대화에 맞춰 사진이나 예약 정보를 제안하는 Now Nudge, 대화를 읽고 먼저 제안하는 카나나 차례로 조금씩 위예요.

## 대본 (지금 35쪽 그대로)

> 그렇다면 이미 있는 기능과는 무엇이 다를까요? Writing Assist는 지금 쓰는 글을 다듬고, 카나나는 카카오톡 대화 안에서, Now Nudge와 Finder는 더 넓은 범위에서 한 번 찾거나 제안합니다. (클릭) Weave는 여러 앱에 흩어진 단서를 이어서 찾고, 쓰던 화면의 키보드 위에서 바로 건넵니다.

## 다시 만들기

```
~/.cache/weave-tools/venv/bin/python tools/cmp_try.py              # 후보 넷의 영상, 덱, 한눈에.jpg
~/.cache/weave-tools/venv/bin/python tools/cmp_try.py --only 가     # 그 후보만 다시
~/.cache/weave-tools/venv/bin/python tools/cmp_try.py --quick 가    # 낭독 없이 그 장만 빨리 찍어 봄(out/cmp_try)
~/.cache/weave-tools/venv/bin/python tools/cmp_try.py --check      # 영상에 넣은 낭독을 받아쓰기로 글과 견줌
```

- 장은 `cmp_new.py`에 있어요(`s_cmpa` ~ `s_cmpd`). 아이콘과 이름은 지금 장의 `slides_new.map_point`를 그대로 써요.
- 낭독과 녹화는 `out/cmp_try/<후보>/`에 따로 둬요.
