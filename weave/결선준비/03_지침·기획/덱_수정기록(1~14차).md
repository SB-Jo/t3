## 12차에서 바뀐 것 (2026-09-29)

**12쪽 차별화 포인트 표** (`tools/apply_round12.py`, 백업 `backups/13_12차요청전.pptx`)

사용자 의견: '맥락 맞춤형'은 Now Nudge의 '상황 인지형'과, '선제적 제안'은 Nudge와 비슷하게 읽히고, '온디바이스'만으로는 온디바이스'만'인지 분명하지 않음. 처음 드린 후보가 문장형이어서 '표의 간결한 명사형과 안 어울리고 장황하다'는 지적을 받았고, 표의 다른 칸 문체(생성·교정형, 연관 행동 안내 등)에 맞춰 다시 골랐습니다.

| 칸 | 전 | 후 |
| --- | --- | --- |
| 유형 (Weave 태그) | 맥락 맞춤형 | 맥락 연결·탐색형 |
| 핵심 역할 (Weave, 두 줄) | 기기 전체에 흩어진 기록 ↵ 연결 및 선제적 제안 | 기기 전체에 흩어진 기록 ↵ 연결 및 연관 맥락 제공 |
| 데이터 처리 (Weave) | 온디바이스 | 온디바이스 전용 |
| 행 제목 (두 줄) | 앱 간 연계 ↵ (Cross-App) | 앱·기록 간 연계 ↵ (Multi-hop) |

- 유형 태그는 글자가 길어져서 보라 알약(103.9 → 142.9px)과 글자 상자를 가운데 기준으로 넓혔습니다. 여백 규칙(글자 상자 = 글자 폭 + 원래 여유, 알약 = 글자 상자 + 양옆 8pt)은 다른 태그와 같습니다. '온디바이스 전용' 글자 상자도 가운데 기준으로 넓혔습니다.
- 가운뎃점은 표의 다른 곳(생성·교정형, 조회·자동입력)처럼 붙여 썼습니다. 핵심 역할은 원래처럼 두 문단(두 줄)이고 '/'는 없습니다(답변에서 줄바꿈을 '/'로 적었더니 사용자가 확인함).
- Weave만 ○인 행을 새로 넣는 대신 '앱 간 연계' 행 제목만 바꿨습니다(사용자 안). Weave 칸 설명 '컨텍스트 기반 연쇄 탐색'과 맞고 표 높이도 그대로입니다.
  - 새 행 후보였던 '기록 통합 검색'(✕✕✕○)은 쓰지 않았습니다. 갤럭시 S26(One UI 8.5)부터 기본 검색 Finder가 캘린더·노트·리마인더·녹음·내 파일을 자연어로 검색합니다([삼성 안내](https://www.samsung.com/us/support/answer/ANS10013035/)).
- 발표자 노트는 그대로입니다.
- PNG·PDF·seamless를 PowerPoint로 다시 만들었고, 픽셀이 달라진 것은 12쪽과 `seamless/p10-12.png`뿐입니다. PDF 글자 층에도 새 문구가 들어갔습니다.

## 확인한 것 · 남은 것

- 1차·2차 모두 적용 직전 백업과 도형 단위로 비교했습니다.
  - 바뀐 도형은 요청 범위뿐입니다. 도형 번호 중복과 남은 그림 관계는 없고, 발표자 노트는 그대로입니다.
- 1~8차 중간 확인은 LibreOffice 렌더로 했습니다. 2026-09-28부터 PNG·PDF와 최종 확인은 PowerPoint 렌더입니다(위 'PNG·PDF 내보내기').
- 손글씨 글꼴 이름: 덱은 원래 덱처럼 'Nanum Pen Script'라는 이름을 씁니다.
  - 여기서 쓴 글꼴 파일(Google Fonts `NanumPenScript-Regular.ttf`)은 이름이 'Nanum Pen'(한글 '나눔손글씨 펜')으로 들어 있습니다.
  - 그래서 이 파일만 설치한 PC의 PowerPoint에서는 손글씨가 다른 글꼴로 보일 수 있습니다. PNG·PDF는 내보낼 때 이름을 맞춰 영향이 없습니다.
  - LibreOffice는 한글 문장부호 앞에 공백을 넣어 보여 줍니다(실제 글자에는 없음).
  - 12쪽 표·10쪽 하단 상자의 일부 글자는 LibreOffice가 자동 맞춤으로 작게 그립니다. 파일에 축소 비율이 저장된 것이 아니어서 PowerPoint에서는 원래 크기로 보일 것입니다.
