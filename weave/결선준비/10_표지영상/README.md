PPT에 넣을 때 할 일이에요(v1과 같음).
1. 영상을 슬라이드 전체(0, 0, 13.333 × 7.5인치)에 맞춰요.
2. [재생] 탭에서 '자동 실행'과 '반복 재생'을 켜요.
3. 포스터 틀은 `표지_포스터.jpg`로 정해요.
4. 영상을 맨 뒤로 보내고, 글 상자를 그 위에 둬요.

4K 영상이 오래된 노트북에서 끊기면 2560×1440으로 줄여 써요(화질은 거의 같음).

```bash
~/.cache/weave-tools/bin/ffmpeg -i 표지_루프.mp4 -vf scale=2560:1440:flags=lanczos -c:v libx264 -preset slow -crf 16 -profile:v high -pix_fmt yuv420p -movflags +faststart -an 표지_루프_1440p.mp4
```

- **그림**: 인트로의 병 그림은 황토·크림색 마개라 노랑에 가까웠어요. 그래서 연한 유리색과 회보라 마개로 바꿨어요.

## 다시 만들기

```bash
cd 10_표지영상
node tools/render.cjs --scale 1 --stills 0,2.4,5.9,9.6,11.5,13.8,16.4   # out/stills/t00.00.png … (빠른 확인용, 1920×1080)
node tools/check_cover.cjs                                               # 프레임마다 검사(30fps, 541장)
node tools/render.cjs --fps 30 --jobs 8 --blur --crf 16                  # → 표지_루프.mp4 (4K, 약 4분 20초)
```

- 환경은 `~/.cache/weave-tools`(node의 playwright-core, `bin/ffmpeg`)와 `~/.cache/ms-playwright/chromium_headless_shell-1243`이에요.
- `--blur`는 두 배 빠르기로 찍어 이웃 프레임을 섞어요(움직임 흐림). 프레임 시각은 0, 1/30, …, 18−1/30이에요. 18초는 0초와 같아서 넣지 않아요.
- 시간과 자리는 `main.js` 맨 위 `T`(시각), `THR`(실 세 가닥 시간), `QTEXT`·`ANS`(검색어), `WS`·`WO`(오른쪽 장면 배율과 기준점)와 `style.css`(휴대폰 `#phone`, 카드 `#cJ`·`#cP`, 결과 `#gres`, 장면 판 `#world`)에 모여 있어요.
- 안쪽 계산(조각 배치, 실, 손)은 모두 줄이기 전 좌표(1920×1080)로 해요. 재고 배치한 뒤에 `#world`만 줄여요. 검사용 값(`__probe`)은 화면 좌표로 바꿔 돌려줘요.
- 조각 자리는 v1과 같은 규칙과 씨앗으로 자동 배치돼요. 그래서 v1과 똑같은 자리에 놓여요. 손으로 고치려면 `PIN`에 `인덱스: [x, y]`를 넣어요.
- 떠다니는 움직임은 모두 주기가 18초(또는 9초)인 사인파예요. 커서 깜빡임도 1초 주기라 18초에서 처음과 맞아요.
