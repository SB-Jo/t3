# 결선 표지 루프 영상 v2 (15초, 4K, 끊김 없이 반복)

PPT 첫 장(표지) 뒤에 깔고 계속 반복해서 트는 영상이에요. 제목("Weave Assist"와 아이콘), 태그라인, 팀원 다섯 명 이름은 영상에 없어요. 왼쪽 빈자리에 PPT 글 상자로 올려요.

- 이야기는 How it Works A1(`09_HowItWorks/장표5/a1.py`)과 같아요. v1(14초)보다 앞뒤가 늘었어요.
  - 빈 구글 검색창에 '지은이네 집들이 때 마신 화이트 와인'을 한 글자씩 쳐요.
  - 실타래 버튼을 누르면 흩어진 기록 가운데 지은 카톡과 그날 사진이 보라 실로 이어지고, '배비치 소비뇽 블랑'을 추천해요.
  - '입력하기'를 누르면 검색어가 '배비치 소비뇽 블랑'으로 바뀌어요. 검색 키를 누르면 쇼핑 결과가 나와요.
  - 마지막에 처음 화면(빈 검색창)으로 돌아가요.
- 실은 v1보다 빨라요. 한 가닥이 0.5초에 그려지고(v1 0.8~0.9초), 버튼을 누르고 추천 카드가 뜨기까지 3.5초예요(v1 7.2초).
- 끝 화면(15초)과 첫 화면(0초)은 화소까지 같아요. 그래서 반복해도 이음매가 보이지 않아요.

## 왼쪽 글자 자리(PPT 제목·이름을 올릴 곳)

- **x 0–846px(1920 기준, 4K에서는 0–1692px), 위에서 아래까지 전부 비워 두었어요.** v1과 같아요. 조각·실·카드·손·단서 표·물결이 여기 들어오지 않아요.
- 배경은 인트로와 같은 연보라 그라데이션이고, 보랏빛 글로 세 개는 모두 오른쪽에 있어요.
- 15초 동안 왼쪽 자리 화소는 첫 장과 비교해 최대 5/255만 달라져요(글로 움직임과 압축). 사실상 멈춘 그림이에요.
- 왼쪽 배경색은 v1 표(이전판 README)와 같아요.

PPT에 넣을 때 할 일이에요(v1과 같음).
1. 영상을 슬라이드 전체(0, 0, 13.333 × 7.5인치)에 맞춰요.
2. [재생] 탭에서 '자동 실행'과 '반복 재생'을 켜요.
3. 포스터 틀은 `표지_포스터.jpg`로 정해요.
4. 영상을 맨 뒤로 보내고, 글 상자를 그 위에 둬요.

4K 영상이 오래된 노트북에서 끊기면 2560×1440으로 줄여 써요(화질은 거의 같음).

```bash
~/.cache/weave-tools/bin/ffmpeg -i 표지_루프.mp4 -vf scale=2560:1440:flags=lanczos -c:v libx264 -preset slow -crf 16 -profile:v high -pix_fmt yuv420p -movflags +faststart -an 표지_루프_1440p.mp4
```

- **검색어를 '지은이네 집들이 때 마신 화이트 와인'으로 정한 이유**: 사용자가 쓴 말은 '"지은이네" 집들이네 마신 화이트 와인'이에요.
  - 따옴표 친 '지은이네'를 더하라는 뜻으로 읽었어요. 그래서 v1 검색어 '집들이 때 마신 화이트 와인' 앞에 '지은이네 '만 붙였어요.
  - '집들이네'는 '집들이 때'의 오타로 봤어요. 예전 덱의 말도 '지은이네 집들이 때 마신 와인'이고, 인트로 v8 01 장면도 '지은이네 집들이 때 먹었던 와인'이에요.
  - 바꾸려면 `소스/main.js` 맨 위의 `QTEXT` 한 줄만 고치면 돼요. 글자 폭은 칸보다 6px 작아요. 더 길어지면 `tools/check_cover.cjs`의 qOverflow가 알려 줘요.
- **결과 화면 글자의 출처**: 인트로 v8 01 장면의 쇼핑 결과 세 개와 칩을 가져왔어요.

## 다시 만들기

```bash
cd 10_표지영상
node tools/render.cjs --scale 1 --stills 0,2.4,4.6,6.9,8.55,10.5,12.6   # out/stills/t00.00.png … (빠른 확인용, 1920×1080)
node tools/check_cover.cjs                                               # 프레임마다 검사(30fps, 451장)
node tools/render.cjs --fps 30 --jobs 8 --blur --crf 16                  # → 표지_루프.mp4 (4K, 약 3분 20초)
```

- 환경은 `~/.cache/weave-tools`(node의 playwright-core, `bin/ffmpeg`)와 `~/.cache/ms-playwright/chromium_headless_shell-1243`이에요.
- `--blur`는 두 배 빠르기로 찍어 이웃 프레임을 섞어요(움직임 흐림). 프레임 시각은 0, 1/30, …, 15−1/30이에요. 15초는 0초와 같아서 넣지 않아요.
- 시간과 자리는 `main.js` 맨 위 `T`(시각), `THR`(실 한 가닥 시간), `QTEXT`·`ANS`(검색어)와 `style.css`(휴대폰 `#phone`, 카드 `#cJ`·`#cP`, 결과 `#gres`)에 모여 있어요.
- 조각 자리는 v1과 같은 규칙과 씨앗으로 자동 배치돼요. 그래서 v1과 똑같은 자리에 놓여요. 손으로 고치려면 `PIN`에 `인덱스: [x, y]`를 넣어요.
- 떠다니는 움직임은 모두 주기가 15초(또는 7.5초)인 사인파예요. 커서 깜빡임도 1초 주기라 15초에서 처음과 맞아요.
