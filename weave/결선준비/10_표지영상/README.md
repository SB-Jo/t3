# 결선 표지 루프 영상 (14초, 끊김 없이 반복)

PPT 첫 장(표지) 뒤에 깔고 계속 반복해서 트는 영상이에요. 제목("Weave Assist"), 태그라인, 팀원 다섯 명 이름은 영상에 없어요. 왼쪽 빈자리에 PPT 글 상자로 올려요.

- 이야기는 How it Works A1(`09_HowItWorks/장표5/a1.py`)과 같아요.
  - 구글 검색창에 '집들이 때 마신 화이트 와인'을 적어요.
  - 실타래 버튼을 누르면 흩어진 기록 가운데 지은 카톡과 그날 사진이 보라 실로 이어져요.
  - 마지막으로 '배비치 소비뇽 블랑'을 추천해요.
- 끝 화면(14초)과 첫 화면(0초)은 화소까지 같아요. 그래서 반복해도 이음매가 보이지 않아요.

## 다시 만들기

```bash
cd 10_표지영상
node tools/render.cjs --stills 0,2.3,6.5,9.9         # out/stills/t00.00.png … (확인용 장면)
node tools/check_cover.cjs                            # 프레임마다 검사(30fps, 421장)
node tools/render.cjs --fps 30 --jobs 8 --blur        # → 표지_루프.mp4 (약 30초)
```

- 환경은 `~/.cache/weave-tools`(node의 playwright-core, `bin/ffmpeg`)와 `~/.cache/ms-playwright/chromium_headless_shell-1243`이에요.
- `--blur`는 두 배 빠르기로 찍어 이웃 프레임을 섞어요(움직임 흐림). 프레임 시각은 0, 1/30, …, 14−1/30이에요. 14초는 0초와 같아서 넣지 않아요.
- 시간과 자리는 `main.js` 맨 위 `T`(시각)와 `style.css`(휴대폰 `#phone`, 카드 `#cJ`·`#cP`)에 모여 있어요.
- 조각 자리는 다음 규칙으로 자동 배치돼요. 손으로 고치려면 `PIN`에 `인덱스: [x, y]`를 넣어요.
  - 휴대폰, 두 카드, 실이 지나는 길, 왼쪽 글자 자리를 피해요.
  - 씨앗 40개로 해 보고 가장 많이 들어가는 배치를 골라요. 결과는 늘 같아요.
- 떠다니는 움직임은 모두 주기가 14초(또는 7초)인 사인파예요. 길이 `LOOP`를 바꾸면 그대로 따라가요.
