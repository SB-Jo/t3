# 장표2 — HOW IT WORKS 모핑 장면판 (시나리오 3가지)

첫 판(`../장표/`, 한 장 + 클릭 애니메이션)은 한 화면에 정보가 너무 많다는 피드백을 받았어요. 그래서 PowerPoint **모핑(Morph) 전환**으로 장면을 잘게 나눴어요. 장마다 보여 주는 것이 적고, 넘길 때마다 카메라가 확대·이동하듯 이어져요.

## 버전

| 파일 | 질문 | 이어지는 단서 | 장 수 |
|---|---|---|---|
| `out/V1_국숫집.pptx` | 그 고기국수집, 이름이 뭐였더라? | 항공권 메일(여행 날짜) → 그 기간 국수 사진(7/13 12:31) → 그날 결제 중 사진 27분 뒤 식당 결제 → 바당식당 | 21 |
| `out/V2_기사님번호.pptx` | 작년에 에어컨 고쳐 주신 기사님, 번호가 뭐였지? | 캘린더 '냉방 수리 방문'(7/3 오전) → 그날 오전 통화만 남김 → 광고 번호를 빼고 방문 시간의 휴대폰 번호 | 19 |
| `out/V3_보고서마감.pptx` | Q1 보고서 마감, 결국 언제로 바뀌었지? | 회의 메모(처음 마감 3/20) → 재무팀 메일(수치 확정이 늦어짐) → 팀장님 '그 건은 다음 주 화요일까지로' → 3/24 (화) | 19 |

세 버전 모두 흐름은 같아요.
1. 상황(대화창에서 받은 질문)
2. 답은 폰 어딘가에
3. **단어로 찾기**와 왜 안 되나
4. **비슷한 것 찾기**와 왜 한 번에 안 닿나
5. Weave 시작(아래 파이프라인 띠가 나타남)
6. **00 사전 준비** → **01 순간 감지** → **02 단서 정리** → **03 연쇄 탐색**
   - 03은 세 번 돌아요. 새 단서가 메모로 돌아오면 띠에 02 ⇄ 03 반복 고리가 켜져요.
7. 멈춤 → **04 전달** → 입력하기 → 정리(핵심 엔진)

발표자는 다음 장으로 넘기기만 하면 돼요. 장 안의 실·형광펜·태그·토큰은 모핑이 끝나면 저절로 나타나요. 장마다 발표자 노트(말할 문장)가 들어 있어요.

## 확인용 출력
- **`out/<버전>_png/`, `out/<버전>_한눈에.png`**: PowerPoint로 렌더한 장별 그림이에요. 장 안 애니메이션이 끝난 상태예요.
- **`out/<버전>_미리보기.mp4`**: PowerPoint 비디오 내보내기예요. 장마다 3.2초 머물며 모핑 전환까지 녹화돼요.

## 다시 만들기

```bash
cd 09_HowItWorks/장표2
~/.cache/weave-tools/venv/bin/python build2.py v1 v2 v3 --png     # pptx + 장별 PNG
~/.cache/weave-tools/venv/bin/python build2.py v1 --video          # + 미리보기 영상
```

- 문구와 기록은 `v1.py` · `v2.py` · `v3.py`의 `SPEC`에서 고쳐요.
  - 화면 제목·부제는 `text`와 `hops`에 있어요.
  - 발표자 노트는 `n_*`와 각 홉의 `note`에 있어요.
- 장면 흐름(단계 순서, 카메라, 흐리게 할 것)은 `scenario.py`의 `build()`에 있어요.
- 그리기와 모핑 전환은 `story.py`, `build2.py`가 맡아요.
- 같은 요소는 모든 장에서 같은 이름(`!!키/부분`)을 써요. 그래서 모핑이 위치·크기·투명도를 이어 줘요.
  - PowerPoint에서 직접 고칠 때 이름을 바꾸면 그 요소의 모핑이 끊겨요.
- 카메라: 세계 좌표의 기록을 장마다 다른 배율로 비춰요.
  - `fit([...])`가 보여 줄 요소들이 화면 가운데 영역(머리 아래, 띠 위)에 들어오게 배율을 정해요.
- 모핑은 PowerPoint 2019 / Microsoft 365에서 재생돼요(이 PC는 M365 16.0.20527). 2016 이하에서는 페이드로 바뀌어요.
