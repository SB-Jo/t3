# How it Works 장표 v4 — 크게 당기고 빼는 모핑 장면, 시나리오 7개 (2026-11-01)

9쪽 'HOW IT WORKS'를 PowerPoint 모핑(Morph) 장면 17~18장으로 나눈 판이다.

- v3(`../장표3/`)에서 사용자 4차 피드백을 받아 처음부터 다시 만들었다.
- 그 뒤 논문 9편 재독과 발표 디자인 조사, 리뷰 네 갈래를 반영했다.
- 끝으로 "실패 장면이 길다"는 피드백에 따라 실패를 2장으로 줄였다.

## 원칙

- **카메라를 크게 당기고 뺀다.** 넓게(0.7배), 중간(1~1.5배), 가까이(2~2.5배)를 오간다.
  - 크게 당기는 곳: 근거를 읽는 장, 실패를 보여 주는 장, 단계가 바뀌는 곳.
  - 한 홉 안에서는 카메라를 세워 두고 하나씩 드러낸다.
- **설명은 초점 바로 옆(34px)에 1~2줄로 둔다.** 뱃지와 부제는 없다. 꼭 필요한 곳에만 작은 한 줄을 둔다(멈춤, 정리, 실패 2장). 자세한 말은 발표자 노트에 있다.
- **파이프라인은 01 순간 감지 → 02 질문 다시 쓰기 → 03 연쇄 탐색 → 04 전달이다.**
  - '00 사전 준비'는 뺐다.
  - 반복 고리(02 ⇄ 03)는 첫 반복 때 나타난다.
- **색 하나에 역할 하나.** 꽉 찬 보라 알약은 단서 칩에만 쓴다.
  - 필터는 점선 테두리, 태그는 흰 테두리, 질문 줄 번호는 연한 보라다.
  - 쓰지 않는 것은 10%로 흐리거나 숨긴다.
- **실패는 2장이다.**
  - "지금 검색은 닮은 것만 찾아요": 결과 셋에 왜 틀렸는지 태그를 붙인다.
  - "답이 두 기록에 흩어져, 한 번에는 못 찾아요": 필요한 두 기록에 태그와 '?' 점선을 둔다. 작은 한 줄은 "앞 기록의 단서로 이어 찾아야 해요"이고, 바로 다음 장이 Weave다.
- **비교 축은 '처음 질문으로 한 번에 찾기' 대 '단서로 다시 쓰며 이어 찾기'다.** 논문들의 향상도 이 고리에서 나온다(Hi-Q 부록 G).
- **한 홉에 가까운 기록 몇 개.** 옅은 점선 실로 후보를 보이고, 가까이 볼 때 후보에 이유 태그를 단다.
- **멈추는 규칙:** "끝까지 없으면 ‘못 찾았어요’라고 해요".
- **노트의 근거 원칙:** 빈칸에는 찾은 기록에서 나온 내용만 넣는다. 날짜 필터로 하나도 안 남으면 날짜를 조금 넓혀 다시 찾는다.
- **시나리오:** 질문엔 답으로 가는 단서가 없고, 중간 기록의 단서로 다음 질문을 다시 써야 답에 닿는다. 추론은 조금만 쓴다. 누구나 공감할 일상과 업무 소재다(반려동물처럼 특정 집단 소재는 뺐다).
