# How it Works 장표 v5 — 흩어진 기록, 키워드·임베딩 실패, 13~14장 (2026-11-01)

9쪽 'HOW IT WORKS'를 PowerPoint 모핑(Morph) 장면으로 나눈 다섯 번째 판이다. 장표4(`../장표4/`)에 사용자가 면세점 판으로 준 5차 피드백 일곱 가지를 일곱 판 모두에 반영했다. 그 뒤 리뷰어 둘(장면, 시나리오·문구)의 지적을 한 번 더 반영했다(첫 v5는 `out/_scene5_v1.py`).

## 바뀐 것 (5차 피드백 → 반영)

| 피드백 | 반영 |
|---|---|
| '~에요' 남발은 LLM 같음. '폰'은 잘 안 쓰는 말 | 화면 설명은 짧은 어구, 끝맺음을 섞었다. '~요'는 "정답은 이미 어딘가에 있어요!" 한 줄뿐. '폰'은 뺐다 |
| 9개 기록이 너무 반듯하게 정렬됨 | 인트로 첫 부분처럼 같은 크기의 작은 조각 30개 남짓을 화면 끝까지(제목 둘레 포함) 흩뿌렸다. 옅게(32%) 하나씩 떠오른 뒤 4개만 보라 테두리로 켜진다. 이야기 기록도 이 장에선 조각이라 답이 미리 읽히지 않는다 |
| 확대·축소가 자유롭지 않고, 가까이 볼 때 정보가 퍼져 있음 | 가까이 볼 때는 기록 하나만 2.8배 안팎으로 크게, 형광펜은 단서 한두 곳만. 찾기 장은 판 + 찾은 기록 + 옅은 후보만(다른 기록, 흐린 질문 판은 숨김), 설명은 찾은 기록 바로 위. 더미 0.7배 → 실패 1.0~1.5배 → 폰 1.4~2.1배 → 판 1.7~1.9배 → 찾기 1.0~1.2배 → 근거 2.5~2.8배 |
| 장이 너무 잘게 쪼개짐(mp4 기준 10~20% 줄이기) | 질문 나누기 + 빈칸, 빈칸 채우기 + 다시 쓴 질문을 한 장씩으로, 멈춤 장은 정리 장의 '멈춤' 알약으로, A1은 필터와 찾기를 한 장으로. 17~18장 → 13~14장 |
| C3 '아내의 언니', 결제 메일로 찾기가 어색함 | 아내 카톡 "여보, 동생이 갈색병 써 봤는데 좋대 / 면세점에서 사면 싸대~" → 9월에 아내가 보낸 쇼핑 링크 "이거 다들 쓰더라" + "에스티 로더 / 어드밴스드 나이트 리페어 50ml" |
| 질문 다시 쓰기에 Query Rewriting 같은 이름 | 질문 판 이름 'Query Rewriting(질문 다시 쓰기)', Reasoning Embedding 판에 Hop 1·Hop 2, 실패 판에 키워드 검색 BM25·임베딩 검색·일반 검색(키워드 + 임베딩). 다시 쓰는 장 설명은 동작만("빈칸에 단서를 넣어 질문을 다시 쓰기"), 위 띠 고리는 '반복'만 |
| 근거가 분명한 판은 실패를 아주 간단히 | A2·B1·B2·C2·C3는 실패 한 장 |
| 일반 검색이 어떻게 찾는지(BM25 형광펜, 임베딩)와 왜 안 되는지 | 결과는 판 옆에 1·2·3 목록으로 뽑혀 나온다(더미에서 날아옴). 같은 단어는 형광펜, 비슷한 뜻은 점선 밑줄(사진엔 '≈ 화이트 와인' 표). 태그는 '왜 아닌지'만. 답이 있는 기록은 결과 밖에 옅은 조각 + 점선 + "‘갈색병’을 알아야 닿는 답"처럼 먼저 알아야 할 단서. A1·C1은 실패 두 장(키워드 → 임베딩), 둘째 장 작은 줄에 "둘을 합쳐도 …" |
| 아내 말에 '면세점' 여지를 주기 | C3 아내 말에 "면세점에서 사면 싸대~". 다른 판도 첫 기록이 지금 상황과 이어지게 맞췄다 |

리뷰어 지적으로 더 고친 것:
- C2의 "오타니가 LA 팀인 건 모름"은 과장이라(일반 임베딩도 대개 잇는다) 실패를 한 장으로 바꿨다. 한 번 검색은 '오타니 유니폼'까지만, 사이즈는 다른 카톡.
- 답 태그 "질문과 딴판"은 임베딩엔 사실이 아닐 때가 있어 "먼저 알아야 할 단서" 태그로 바꿨다.
- 다시 쓰기 노트에 "처음 질문엔 없던 X가 이제 질문에 들어 있다, 한 번 검색과 다른 점"을 넣었다. C3 노트의 "Reasoning Embedding은 별명을 안다"는 "갈색병은 흔한 별명이라 다시 쓴 질문이 링크와 가까워진다"로.
- A1 실패 부제 "사진엔 ‘화이트 와인’이란 글자가 없음", 임베딩 노트 "카톡엔 와인 얘기가 없어 순위가 밀림". C1 가족 단톡방 본문의 '엄마:'는 보낸 사람 표시로 뺐다. B2 첫 질문 "지난번 동창회, 결국 어디로 정했지?". C2 시각은 LA 오후 4시(한국 다음 날 오전 9시).
- 가까이 보는 장 설명은 칩과 겹치지 않게 이유만(예: "잡은 곳 = 예약한 곳", "오타니 = LA 다저스", "매장엔 ‘갈색병’ 대신 이 이름과 용량으로").
- 노트 말투: "요즘 검색은 보통 키워드 검색과 임베딩 검색을 함께 씁니다", "질문 다시 쓰기, Query Rewriting", "보내기는 직접 누릅니다".
- 마감: 답이 길면 '멈춤'이 아래 줄로 가고 질문 판이 그만큼 길어짐, 첨부 아이콘은 문서 모양, 통합 검색 시트가 클 때 이중 테두리 없앰, 와인 라벨 알약 불투명, 사진은 비율 맞춰 잘라 냄.

## 6차 피드백(같은 날): 근거가 죄다 카톡 → 앱을 섞음

| 피드백 | 반영 |
|---|---|
| 근거가 죄다 카톡으로 이어짐(특히 아내 판). GPS·월렛도 trigger가 될 수 있음 | 판마다 근거 앱을 섞었다. C3: 카톡 → 갤러리(그날 밤 캡처해 둔 제품 페이지). C1: 전화(어제 엄마와 통화 녹음 텍스트) → 카톡. B2: 카톡 → 삼성 월렛(그날 밤 회비 카드 결제). C 판 질문 판엔 '지금 상황에서 만든 질문' 아래에 그 질문을 만든 신호(위치, 월렛 탑승권, 대화 상대)를 작은 칩으로 |
| 마지막 카드에 카톡 아이콘이 2개 | 건네기 카드의 근거는 앱마다 아이콘 하나. 같은 앱 근거 둘은 아이콘 하나 아래 두 줄(C2 민호 카톡 둘). C 판은 지금 위치(지도)까지 세 앱. 정리 장에서도 같은 대화방 기록 둘은 카드 하나로 묶음 |
| 아내 말투 'ㅠㅠ'(임원 50대) | 모든 메시지에서 'ㅠㅠ', 'ㅋㅋ', 'ㅎㅎ', '헐'을 뺐다. C3 답장 "그걸 기억했네? 고마워, 여보!", C2 "진짜? 형 최고!", C1 "응, 그거야! 역시 다 아네" |

판별 근거 앱: A1 카톡 → 갤러리, A2 카톡 → 갤러리, B1 노트 → 메일, B2 카톡 → 월렛, C1 전화 → 카톡(+ 지도), C2 카톡 둘(한 아이콘, + 지도), C3 카톡 → 갤러리(+ 지도).

리뷰어 추천: 장면 리뷰는 A1·B1·C3(시간이 없으면 A2·B1·C2), 문구 리뷰는 A1·B2·C1(선물 이야기를 원하면 C3). A2는 답 캡처가 질문과 뜻이 가까워 실패가 가장 약하다.
