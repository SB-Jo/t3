## 움직임을 만든 방법

- 영상을 넣지 않고 PowerPoint 기능만 써요. 그래서 글을 PowerPoint에서 바로 고칠 수 있고, 파일도 가벼워요.
- 장이 바뀔 때는 모핑(같은 이름 `!!키`의 도형이 위치·크기·투명도를 이어 감).
- 장 안 효과는 `motion.py`가 씀: 떠오르기(감속), 넘쳤다가 제자리(0.6 → 1.05 → 1), 형광펜 쓸기, 한 글자씩, 커서 깜빡임(반복), 흐려지기(투명도 30%), 물결(커지며 사라짐), 곡선 비행.
- PowerPoint는 한 도형의 이동 경로를 더하지 않고 바꿔 끼워요(2026-11-08 시험). 그래서 잠깐 보이는 것은 화면 밖(+1600px)에 두고 나타날 때 제자리로 옮기고, 자리를 바꾸는 것은 마지막 자리에 둔 채 처음 자리로 옮겨 두었다가 되돌려요. 덕분에 편집 화면, 썸네일, PNG는 마지막 상태와 같아요.
- 날아 들어오는 것은 그 전까지 숨김(첫 효과를 '나타내기'로).

## 다시 만들기

```bash
cd 09_HowItWorks/Claude
~/.cache/weave-tools/venv/bin/python build.py            # ../HowItWorks_Claude.pptx (흐린 배경용으로 PowerPoint 렌더를 한 번 먼저 함)
~/.cache/weave-tools/venv/bin/python build.py --png      # + out/png, out/한눈에.png
~/.cache/weave-tools/venv/bin/python build.py --video    # + out/HowItWorks_Claude_미리보기.mp4 (클릭 효과도 저절로)
```

- 글과 자리: `build.py`의 장 함수(`s_kw`, `s_hop1` …), Appendix는 `appendix.py`. 노트의 `(클릭)` 수는 장의 클릭 수와 같아야 해요(빌드가 알려 줌).
- 사진: `build.py`의 `PH`. 출처는 [`assets/CREDITS.md`](assets/CREDITS.md)와 Appendix 마지막 장.
- Appendix 근거: [`리서치_Appendix근거.md`](리서치_Appendix근거.md) (PDE 논문, Apple 발표, HippoRAG 오류 분석, 문구 점검).
- `out/`(렌더, 미리보기 영상)과 `assets_cand/`(사진 후보)는 작업 컴퓨터에만 둬요.
